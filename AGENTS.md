# CursingStandards agent guide

This repo is a shared standards library for agent-friendly project setup.

## Start here

1. Read `docs/INDEX.md`.
2. Open only the linked task doc.
3. Keep context small and avoid loading unrelated repos or all docs.

## Routing

- Desktop restore / plugin setup: `desktop-cursor-recovery.md` and `desktop-cursor-recovery.reference.md`
- Agent context rules: `docs/agent-context-budget.md`
- Handoff and doc structure: `docs/agent-structured-docs.md`
- Python rules: `docs/python.md`
- PostgreSQL rules: `docs/postgresql.md`

## Shared rules

- Keep instructions brief and hierarchical.
- Prefer links over long transcripts.
- Do not store secrets, PATs, or private repo lists in public docs.
- Update docs only when behavior, setup, or durable decisions change.
